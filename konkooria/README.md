# کنکوریا — نسخه آزمایشی (APK از طریق گیت‌هاب)

## مراحل (فقط یک‌بار)
1. زیپ را Extract کن. یک ریپازیتوری جدید در github.com بساز (مثلاً konkooria).
2. در صفحه‌ی ریپازیتوری: Add file ← Upload files ← **همه‌ی فایل‌ها و پوشه‌های داخل پوشه‌ی استخراج‌شده** را بکش و Commit بزن.
   (پوشه‌ی .github مهم است. اگر آپلود نشد: Add file ← Create new file ← نام `.github/workflows/build-apk.yml` و محتوای فایل را Paste کن.)
3. تب Actions را باز کن؛ ساخت خودکار شروع می‌شود (حدود ۸ تا ۱۲ دقیقه). اگر شروع نشد: Build Konkooria APK ← Run workflow.
4. بعد از سبز شدن، از صفحه‌ی اصلی ریپازیتوری، بخش Releases (سمت راست) را باز کن و فایل **Konkooria.apk** را روی گوشی دانلود کن.
5. روی گوشی نصب کن (اجازه‌ی «نصب از منابع ناشناس» را بده؛ اگر Play Protect هشدار داد: Install anyway).

هر بار فایلی را در ریپازیتوری تغییر بدهی، نسخه‌ی جدید APK خودکار ساخته می‌شود و روی نسخه‌ی قبلی نصب می‌شود (اطلاعات حفظ می‌شود).

## ساختار
- www/ : خود برنامه (HTML/CSS/JS)؛ محتوا در www/data.js
- assets/ : آیکون و اسپلش
- .github/workflows/build-apk.yml : ساخت خودکار APK
